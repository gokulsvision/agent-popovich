# Pro case

Head coach. Training data. How pro players and pro staffs actually play the same problems this team has.

This is not a video archive. Do not commit match footage. Each case is a researched markdown page: what happened, the decision, the principle, a public link, a start time you can click, and the amateur translation.

Illegal outputs: ripped video in the repo, a page with no public URL, installing an elite starting height on a rec back line, mixing doctrine / our matches / pro evidence on one page.

## Why a separate folder

Doctrine is the rule. A pro case is evidence for the rule. Our match notes are evidence about us. Mixing those three on one page makes the wiki unsearchable.

## Input

- "Research how Neuer comes off his line"
- "Add a City rest-defence clip"
- "How do good amateur-translatable corners work in the Premier League"
- A public URL plus "write this up as a case"

## Ship rule

A pro case does not ship without a public URL and a start time you can click. No URL, no page.

If two cases teach the same rule, keep both.

When the page does not exist yet, research from public sources, write the case in `wiki/pro/_template.md`, then stop. A timestamp and a description beat an illegal video file.

## Output

One page under `wiki/pro/<topic>/`. Add it to `wiki/pro/INDEX.md` by problem, not by club.

Amateur translation is mandatory so the agent does not install a high line this team does not have.

## How game-analysis uses this

After scoring our clip, attach one pro case as "this is the picture." If no case exists for that mistake, queue this workflow instead of inventing a lecture.
