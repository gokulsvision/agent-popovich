# Come off the line

Canonical for this slug.

## Rule

Come if you win the race or the touch is heavy. Stay if unsure, if the attacker is set, if a defender recovers. Commit. Call before you move.

Half-coming is how you get chipped and how you lose the 1v1. The decision is binary.

## Cue

Can I get there first. If yes, go now. If no, set. If you do not know, stay.
