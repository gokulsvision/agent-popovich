# Amateur constraints

This is a rec team. Two team sessions and one GK session around a match. One theme per session. People work. People miss. Attendance is a fact, not a moral failure.

## Rule

Do not install a system that needs eleven people who trained it twice this week. If six showed, the session is for six. The theme does not change because the turnout did.

NOOP changes dose for the named athlete. It does not change the team's one thing.

No medical advice. Load logs are load logs.

## Cue

If the plan needs a whiteboard and a full week of walkthroughs, it is the wrong plan.
